📦 Stock Management System

A simple yet efficient Java-based Stock Management System designed to handle and manage product inventory using MySQL database integration.
This project focuses on performing essential stock operations in an easy and structured way.

✨ About the Project
This system helps users manage stock records by allowing them to add, view, search, and delete products from the database.
It demonstrates how Java can be used with MySQL through JDBC to build a real-world database-driven application.

🚀 Key Features
Add new products to inventory
View all available stock details
Search products using ID or name
Delete unwanted product records
Secure database connection using JDBC
Simple and user-friendly console interface

🛠️ Tech Stack
Java (Core Java)
JDBC
MySQL
Git & GitHub

⚙️ How to Run This Project
Clone the repository
git clone https://github.com/NivethaValliyappan/Stock-management-system.git
Open the project in IntelliJ IDEA / Eclipse
Import the database file:
database/stock_management.sql
Add MySQL Connector JAR (available in lib folder)
Run the main Java file and start managing stock!
